# 처음부터, CAD 수학

[앱 열기](https://minjaedy.github.io/cad-math/)

제공받은 **수학에서 CAD까지 — 144단원 완성교재**의 12권·144단원, 개념, 순서와 실습을 유지한 교재 겸 문제집입니다. 회원가입이나 Google 로그인 화면은 없습니다.

## 공부 흐름

- 원본 예제 576개·문제 1,152개에 예제 144개·문제 864개를 추가했습니다. 전체 **예제 720개·문제 2,016개**입니다.
- 개념 → 풀이 예제 → 기본·응용·심화 문제로 구성합니다. 수치 답은 자동 채점하고 서술형은 해설·점검표로 확인합니다.
- 개념 분량, 풀이 단계, 문제 난이도로 하루 약 30분씩 **551회차**를 계획했습니다. 실제 소요 시간은 학습자에 따라 다릅니다. 매 회차 개념·예제·문제가 모두 있습니다.
- 현재 단원의 모든 문제를 정답 또는 서술형 자기점검으로 완료해야 다음 단원으로 넘어갑니다. 틀린 문제는 다시 풀 수 있습니다.
- 하루 목표 이상 공부하면 다음 미완료 회차부터 이어집니다. 날짜가 바뀌어도 풀던 문제를 건너뛰지 않습니다.
- 문제집 필터, 오답 복습, 단원 검색, 풀이 접기, 글자 크기, 집중 모드, 라이트·다크 모드를 제공합니다.

## 기기 연결과 보관

**아이폰과 아이패드에서 같은 개인 학습 링크를 열면** 답안·노트·진도를 같은 Firebase Realtime Database에 저장합니다. 연결된 앱의 ‘기기 연결·동기화’에서 다른 기기로 옮길 링크를 복사할 수 있습니다. 일반 공개 주소만 처음 열면 우선 해당 기기에 저장합니다.

개인 링크의 `#connect=...`는 학습 공간 접근 권한이므로 공개하지 마세요. 실제 연결 키와 서비스 계정은 저장소에 포함하지 않습니다. URL 조각은 GitHub 서버로 전송되지 않으며 앱이 읽은 뒤 주소 표시줄에서 지웁니다. 연결된 기기의 설치 manifest에만 개인 시작 주소를 넣고 앱 고유 ID와 scope를 유지합니다.

로컬에 즉시 저장한 다음 변경된 필드만 서버로 전송합니다. 오프라인에서 공부한 내용은 다시 연결되면 동기화합니다. 두 기기의 서로 다른 답안·노트를 합치며, 같은 항목을 동시에 수정하면 서버에 나중에 반영된 값이 남습니다. 다른 기기의 변경은 앱을 다시 열거나 활성 상태에서 약 15초마다 확인합니다.

학습 기록에는 **자동 만료나 정기 삭제를 설정하지 않았습니다.** 무료 서비스의 정책·계정 상태가 영구히 보장된다는 의미는 아닙니다. ‘학습 기록 저장’으로 JSON을 내려받고 ‘책 사용법 → 기록 불러오기’로 복원할 수 있습니다.

## 학습 알림

- 학습 시간 안내: 매일 **오전 11시**, 한국 시간.
- 푸시 알림: **오후 10시**, 그날 목표를 끝내지 않은 경우에만 기기당 하루 한 번.
- Cloudflare 예약 작업이 실행하므로 앱을 열어 두지 않아도 됩니다. 5분 간격 작업 및 운영체제의 전달 상태에 따라 도착이 지연될 수 있습니다.
- 각 기기에서 설치 후 ‘학습 알림 → 이 기기에서 알림 켜기’를 한 번 눌러야 합니다. iPhone/iPad에서는 Safari로 홈 화면에 추가한 앱에서 허용합니다.
- 알림 전달 기록만 7일 후 정리합니다. 학습 기록은 삭제하지 않습니다. 실제 기기 수신은 권한 허용 후 확인해야 합니다.

## 구성과 보안

| 역할 | 리소스 |
| --- | --- |
| 정적 앱 | GitHub Pages `minjaedy/cad-math` |
| 학습 기록 | Firebase `cad-math-minjaedy`의 RTDB `learning/main` |
| 비공개 기록 API·예약 푸시 | Cloudflare Worker `cad-math-service` |
| 기기 구독·알림 중복 방지 | 별도 D1 `cad-math-service` |

RTDB 규칙은 클라이언트 읽기·쓰기를 거부하며 만료 날짜를 두지 않습니다. Worker가 전용 서비스 계정으로 접근하고 개인 연결 키·허용 Origin·입력 스키마를 확인합니다. 프런트엔드에는 Firebase 관리 키가 없습니다. 기존 구안행토·MIXROOM·TEMPO 프로젝트, 데이터와 알림 키를 재사용하지 않습니다.

Worker secrets: `FIREBASE_ACCOUNT`, `LEARNING_KEY`, `VAPID_PRIVATE_KEY`, `VAPID_PUBLIC_KEY`. 실제 값은 저장소 밖에서 관리합니다. 다른 사람의 독립된 학습 기록을 지원하려면 이 단일 공간의 키를 공유하지 말고 별도 공간을 구성해야 합니다.

## 개발·검증·배포

Node.js 24, Python 3.12 이상을 사용합니다.

```sh
npm ci
npm run build
npm test
npm ci --prefix cloudflare
npm test --prefix cloudflare
npm run build --prefix cloudflare
npm run preview
```

미리보기는 `http://127.0.0.1:8788/`입니다. 로컬에서는 실제 서버의 Origin 제한에 따라 서버 동기화를 사용하지 않습니다.

- `source/textbook.html`: 원본. 기존 개념·순서·문제를 변경하지 않습니다.
- `source/extra-profiles.cjs`, `scripts/expand.cjs`: 추가 예제·수치 문제·서술형 문제와 해설.
- `scripts/plan.cjs`: 전체 문제를 빠짐없이 배정하는 일일 계획.
- `scripts/build.py`: 원본에서 데이터·렌더러·스타일·폰트를 추출하고 앱을 구성합니다. `dist/`는 생성물입니다.
- `public/study-adapter.js`, `study-core.js`: 일일 학습·단원 완료·진도 상태.
- `public/cloud-sync.js`: 서버 연결, 오프라인 대기열, 기기별 푸시 설정.
- `public/sw-template.js`: 앱 경로로 제한한 오프라인 캐시·설치·푸시.
- `scripts/icons.cjs`: SVG에서 설치용 PNG를 만듭니다.
- `tests/`: 원본 보존, 문제 배정·진도 잠금, 채점·백업, 두 기기 동기화·오프라인 복구, 캐시 분리 검사.
- `cloudflare/tests/`: 접근 거부, 입력 검증, 한국 시간 예약·중복 방지 검사. 실제 알림은 보내지 않습니다.

콘텐츠 검사는 전체 구조·배정·유한 수치 및 대표 대수·기하 계산을 확인합니다. 모든 해설이 전문가 전수 검수를 받았다는 의미는 아닙니다.

`.github/workflows/pages.yml`은 `main` 변경 시 빌드와 테스트 후 **dist만** Pages에 배포합니다. Firebase·Cloudflare는 별도 배포합니다.

```sh
firebase deploy --only database --project cad-math-minjaedy
npm run deploy --prefix cloudflare
```

D1 최초 테이블은 `cloudflare/schema.sql`로 만듭니다. 설치 ID `/cad-math/`, scope `./`, 셸 캐시 `cad-math-shell-<content-hash>`를 사용하며 업데이트 때 이 앱의 이전 셸 캐시만 지웁니다. 학습 키 `cad-math-full-144-v1`과 원본 JSON 백업 호환을 유지합니다.
